# CodeQuiz — Store Listing

All text shown on Google Play, in every store language. Paste it into Play Console → **Grow users → Store presence → Main store listing**. The settings and declarations are in [001-google-play-store.md](001-google-play-store.md).

| Field | Limit |
| --- | --- |
| App name | 30 |
| Short description | 80 |
| Full description | 4,000 |
| Release notes | 500 |

**Languages:** English `en-US` (default). The app UI is English only.

Don't name other companies' certifications or products as endorsements (for example "LinkedIn skill assessment"): Play's metadata policy rejects listings that imply an affiliation. Naming the technologies a topic covers is fine.
